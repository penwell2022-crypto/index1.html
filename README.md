## เมนูบนหน้าเว็บ
| เมนู | คำอธิบาย |
|---|---|
| ① การ์ดธาตุ | การ์ดสี 5 ธาตุ จำนวนภาวะ/อาการ คำช่วยจำ |
| ② บันไดความรุนแรง | หย่อน → กำเริบ → พิการ → ออกจากกาย → แตก → ขาด |
| ③ แผนที่กลุ่มธาตุ | ตาราง ● ธาตุที่เกี่ยวข้องในแต่ละกลุ่ม + กราฟแท่ง |
| ④ สำรวจเอง | เลือกกลุ่ม / ค้นหาอาการ |
| ⑤ แบบทดสอบ | ก) เลือกตอบ 8 ข้อ · ข) ลากวางจับคู่ |

## โครงสร้างไฟล์
```
index.html        หน้าเว็บ
style.css         สี/รูปแบบ
app.js            โค้ดอ่าน Excel และสร้างแผนภาพ
data/data.xlsx    ไฟล์ข้อมูล (สำเนาที่มีเฉพาะชีตข้อมูล)
LICENSE           ข้อกำหนดลิขสิทธิ์
.nojekyll
```

## อัปเดตข้อมูล
แก้ข้อมูลใน Excel → บันทึกสำเนาที่มีเฉพาะชีตข้อมูล ชื่อ `data.xlsx` → อัปโหลดทับใน `data/`

## ทดสอบบนเครื่อง
```bash
python -m http.server 8000
# แล้วเปิด http://localhost:8000
```
